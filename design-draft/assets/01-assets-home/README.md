# 01-assets-home 静态资源

## 资源说明

- `hero-card-background.png`：资产卡黑蓝霓虹背景图，高清位图。
- `brand-sol.svg`：顶部品牌标识。
- `icon-top-scan.svg`、`icon-profile-circle.svg`：顶部右侧红框标记图标。
- `icon-chain-contract.svg`：资产卡链上合约图标。
- `icon-send.svg`、`icon-receive.svg`、`icon-stake.svg`、`icon-scan.svg`：快捷操作图标。
- `icon-node-status.svg`、`icon-validator.svg`、`icon-private-account.svg`、`icon-network-status.svg`：状态卡图标。
- `token-btc.svg`、`token-eth.svg`、`token-sol.svg`、`token-xrp.svg`、`token-wld.svg`：行情列表币种图标。
- `nav-assets-active.svg`、`nav-privacy.svg`、`nav-contract.svg`、`nav-dpos.svg`、`nav-account.svg`：底部导航图标。

## 使用建议

SVG 图标建议按设计稿尺寸等比缩放使用；`hero-card-background.png` 作为资产卡背景图使用，前端叠加文字和交互控件。
